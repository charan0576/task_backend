# Predefined closing cards

Drop your finished closing design here (logo, spotlight title, AI disclosure). The QR code is added on top automatically, after the card's midpoint.

Naming (first match wins, .jpg, .jpeg, .png or .webp):
- `food-premium.png` for one cause and style
- `premium.png` or `news.png` for a style across causes
- `closing.png` for every video

Use a 16:9 image (1280x720 or larger), or a wide image on a background colour close to your palette. If no file matches, a generated closing card is used with the uploaded logo.

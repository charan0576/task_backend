# Predefined cause artwork

Drop one image per cause (or per cause and beat) here. The renderer uses it as the background for matching scenes, ahead of stock clips and the built-in icon artwork.

Naming (first match wins, .jpg, .jpeg, .png or .webp):
- `food-intro.jpg` for one beat (intro, org, services, campaign, cta, closing)
- `food.jpg` for every beat of that cause

Causes: food, money, community, education, health. Use 16:9 images of at least 1280x720. Use only images you have rights to.
